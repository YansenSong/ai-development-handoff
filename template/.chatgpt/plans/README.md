# Implementation Plans

This directory contains project-owned implementation plans created through the ChatGPT → GitHub → local coding agent handoff workflow.

## Naming

Use:

```text
YYYY-MM-DD-short-description.md
```

Examples:

```text
2026-08-26-add-workspace-status.md
2026-08-28-fix-auth-refresh-flow.md
```

Do not overwrite an existing plan just to reuse its filename. Add a short disambiguating suffix when necessary.

## Ownership

Actual plan files in this directory belong to this project and are part of its engineering history.

Workflow-template updates must not delete or overwrite these plans.

## Authoring

New plans should follow `../PLAN_TEMPLATE.md` and the lifecycle defined in `../WORKFLOW.md`.

A plan should capture durable execution decisions rather than a transcript of the planning conversation.
